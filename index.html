Nghiên Cứu Cấu Hình Hệ Thống & Dự Án Nguồn Mở

Hệ thống lưu trữ các tập lệnh tùy chỉnh hạ tầng kỹ thuật, thiết lập môi trường giả lập, và các kịch bản tự động hóa (Automation Scripts).

  • Android Custom Kernel & Boot Configurations

    Tích hợp mô-đun APatch, thiết lập hệ thống defconfig tùy chỉnh, và kịch bản flash boot.img tự động cho môi trường kernel giả lập và thử nghiệm.

  • WSL2 & Termux Environment Scripts

    Chuỗi kịch bản tự động hóa giúp triển khai các chuỗi công cụ biên dịch (toolchains như Clang, GCC) và giả lập Virtual File System (VFS) trong môi trường Terminal di động.

  • Local Network Traffic Balancing

    Cấu hình định tuyến kỹ thuật sâu qua mwan3 trên OpenWrt, tích hợp UCI shell scripts nhằm phân bổ và quản lý luồng dữ liệu (load balancing policies) cho kiến trúc mạng đa luồng (multi-WAN).
